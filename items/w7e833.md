# Lock file for concurrent cake processes

.cake/.lock with fd-lock around load → save → commit, so parallel cake processes (TUI, your shell, Claude) run one after another. Without it parallel commands fail on git's index.lock and leave files uncommitted, see [[2wkhyp]].
