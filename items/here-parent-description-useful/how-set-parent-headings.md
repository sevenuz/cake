# How to set parent headings apart in the tables?

In the mine table a parent's title is a heading above its children, but it looks like a row (same dim color) and blends into the table.

- a) tree marker and own color: "▾ Dashboard: one screen…" in the hint color, children indented under it (recommended)
- b) blank line before each group, heading underlined
- c) heading as a thin rule: "── Dashboard: one screen… ──"
