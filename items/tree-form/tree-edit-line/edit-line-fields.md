# How to move between edit line fields?

h/l already walk the modules.

- a) no field cursor: keys set fields directly (t/n/x status, w who, p prio, :due, :deadline); the line only shows them (recommended)
- b) <cr> enters the line, h/l move fields, <esc>/jk leave
- c) <tab>/<s-tab> move fields, h/l stay for modules
